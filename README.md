# 🚀 Enterprise DevSecOps CI/CD Platform

## 📖 Overview

This project demonstrates how to build a production-style DevSecOps CI/CD platform from scratch using modern DevOps tools and best practices.

The project will cover:

- Git & GitHub
- GitHub Actions
- Python Flask
- Docker
- Jenkins
- SonarQube
- Trivy
- Kubernetes
- Helm
- Prometheus
- Grafana

---

# 🎯 Project Goal

Build an end-to-end DevSecOps pipeline that automatically:

1. Builds the application
2. Runs tests
3. Scans for vulnerabilities
4. Creates Docker images
5. Deploys to Kubernetes
6. Monitors the application
